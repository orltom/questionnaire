# Questionnaire

A platform for creating and running questionnaires. The first supported type is a Quiz.

## Motivation

A personal playground to learn about new technologies and concepts. It explores all
facets of the application lifecycle, from development to operations.

## Repository

This is a mono repo. The OpenAPI document in `api/` is the contract shared by all
applications.

```
api/openapi.yaml     API contract
backend/             Go back-end application
mobile/              mobile application (planned)
```

## Status

The back-end is under development, the mobile and web applications have not been
started yet.
